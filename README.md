# 🦁 FarsiScript – زبان برنامه‌نویسی فارسی

[![CI](https://github.com/Dan13681989/farsiscript/actions/workflows/run-tests.yml/badge.svg)](https://github.com/Dan13681989/farsiscript/actions)
[![PyPI](https://img.shields.io/pypi/v/farsiscript-lang)](https://pypi.org/project/farsiscript-lang/)
[![License](https://img.shields.io/github/license/Dan13681989/farsiscript)](LICENSE)

یک زبان برنامه‌نویسی کامل به زبان فارسی با مفسر، کامپایلر C، و ۳۰+ کتابخانهٔ استاندارد.

## 🚀 نصب

pip install farsiscript-lang

## ✨ نمونه کد

چاپ "سلام دنیا!";

اگر (نمره > 90) {
    چاپ "عالی";
} درغیراینصورت {
    چاپ "رد";
}

تاوقتی (i < 10) {
    چاپ i;
    i = i + 1;
}

## 🧰 ابزارها

- `fs run file.fs` – اجرای مستقیم
- `fs compile file.fs` – کامپایل به C
- `fs repl` – محیط تعاملی
- `fs fmt file.fs` – فرمت‌کنندهٔ خودکار
- `fs debug file.fs` – اشکال‌زدا
- `fs check file.fs` – بررسی نوع ایستا
- `fs turtle file.fs` – گرافیک لاک‌پشت
- `fs database file.fs` – پایگاه داده SQLite
- `fs install <package>` – مدیر بسته
