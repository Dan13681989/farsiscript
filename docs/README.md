```bash
pip install git+https://github.com/Dan13681989/farsiscript.git
# یا
git clone https://github.com/Dan13681989/farsiscript.git
cd farsiscript

متغیرها، عملگرها، شرط‌ها، حلقه‌ها، توابع، آرایه‌ها، دیکشنری‌ها

کتابخانهٔ استاندارد: ریشه_دوم, قدر_مطلق, سقف, کف, طول_رشته, بزرگکن, کوچککن, زمان_اکنون, عدد_تصادفی, اجرا, فرمت_تاریخ, تکرار_رشته, نوع, طول_آرایه
کامپایل به C: ./fs compile file.fs
مدیریت خطا: سعی کن ... بگیر
کلاس‌ها و اشیاء، وراثت، ماژول‌ها

}
